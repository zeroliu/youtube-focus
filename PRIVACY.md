# YouTube Focus privacy policy

Last updated: September 19, 2026

YouTube Focus filters recommendations on the desktop YouTube homepage and watch pages according to the interests you enter.

## Information the extension handles

The extension stores your interests prompt, TypeSafe API key, filtering preferences, and API usage counts and estimated costs locally in your Chrome profile. Recent usage records include request timestamps. Relevance results are cached in the extension's memory to avoid repeated API requests.

When filtering is enabled, the extension reads recommended videos' IDs, titles, channel names, and visible metadata. It sends that information and your interests prompt directly to the TypeSafe API over HTTPS. Your API key authenticates those requests. TypeSafe returns relevance scores so the extension can dim or hide unrelated videos.

The extension does not send YouTube cookies, account details, watch history, transcripts, or thumbnail images. It does not include advertising or analytics trackers, or send data to a server operated by the extension's developer.

## How information is used and shared

The extension uses this information to filter recommendations, remember your settings, and show local API usage estimates. It does not sell user data, use it for advertising, or use it for credit or lending decisions.

TypeSafe processes API requests under its own terms and privacy practices. Its handling and retention of API data are controlled by TypeSafe and your TypeSafe account settings, not by this extension. The extension cannot delete information already received by TypeSafe.

## Your controls

You can change your interests, replace or remove your API key, or turn filtering off in the popup. Turning filtering off stops new classification requests; requests already sent may still complete. Uninstalling the extension removes its locally stored extension data from your Chrome profile. Contact TypeSafe for requests concerning data held by TypeSafe.
